# Starter API contracts

| Service | Method | Endpoint | Purpose |
|---|---|---|---|
| Product | GET | `/api/products` | List sample products |
| Product | GET | `/api/products/{id}` | Find one product |
| Cart | GET | `/api/cart` | Read demo cart |
| Order | GET | `/api/orders` | List demo orders |
| Order | POST | `/api/orders` | Create a demo order |

These are starter contracts. Add request validation, error responses, authentication and persistence before production use.
